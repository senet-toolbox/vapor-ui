API Reference

Generic Item Structure

Item(T) is a global type used across the framework for data consistency.

Item(T) { value: T, label: []const u8, icon: ?IconTokens, description: ?[]const u8, link: ?[]const u8, is_selected: bool, }

Custom Row Callback

Provide a custom function to render rows. Receives the dialog and the item pointer.

dialog.row_component = myCustomRowFn;

Static Methods

Use .open to trigger the dialog from any Button or Click event.

Button(ComboBoxDialog(T).open, .{&my_dialog})
