marquee-ui ⇒

marquee-ui

Auto-scrolling marquee with left, right, up, and down motion. Configurable speed, gap, and item count.

Marquee

Auto-motion marquee supporting all four scroll directions with variable speed input. Items loop seamlessly with zero layout shift.

Directions

Pick a direction with the .direction field. Horizontal marquees scroll left or right, vertical marquees scroll up or down.

Left (default)

Slides advance to the left continuously. This is the default behavior when no direction is specified.

Fast — speed_ms: 5000

Energetic pace, good for logo strips and rapid-cycle announcements.

Blazing — speed_ms: 2000

Very fast. Items become hard to read at this speed — use sparingly.

Custom Item Renderer

Pass children to render() to use any layout you like instead of the built-in slide template. Repeat and gap let you tune density.

Badge-style tiles

A monospaced badge tile composed inline. Children render once per cycle — set repeat to tile them.

Installation

Marquee uses CSS keyframes that must be registered once at startup. Call Marquee.new() before mounting any pages.
